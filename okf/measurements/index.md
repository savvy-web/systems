# Measurement

* [Copilot reports SessionStart source new and gives an MCP server no project](copilot-plugin-host-environment.md) - Measured by pluginfinity on Copilot CLI 1.0.92 (2026-10-07): a fresh session's SessionStart source is new, not startup, so a startup-matched hook never ran there; an MCP server starts at the plugin root with no roots capability and no project variable, so it cannot learn the project.
* [The pluginfinity Claude build matches plugins/silk except for listed, intended differences](claude-build-fidelity-against-legacy-plugin.md) - Compared 2026-10-06/07 at pluginfinity 0.3.0: plugin/builds/claude carries every plugins/silk manifest field, the same 16 hook registrations, byte-identical SessionStart context and 40 of 42 byte-identical skill and agent files; every other difference is intended and listed here.
* [What Claude Code passes to a plugin's monitors and the Bash tool (2.1.291/2.1.292)](claude-code-plugin-process-environment.md) - Measured 2026-10-06/07: a Claude Code monitor process runs in the project with none of CLAUDE\_PROJECT\_DIR, CLAUDE\_PLUGIN\_ROOT, CLAUDE\_PLUGIN\_DATA or CLAUDE\_SESSION\_ID, only CLAUDE\_CODE\_SESSION\_ID; the Bash tool sees only CLAUDE\_CODE\_SESSION\_ID plus the CLAUDE\_ENV\_FILE exports, and CLAUDE\_CODE\_SESSION\_ID equals the hook session\_id.

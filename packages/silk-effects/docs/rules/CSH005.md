# CSH005 — changeset-dependency-table-format

Validates that a `## Dependencies` section contains a properly structured
dependency table.

## What it checks

A `## Dependencies` section must contain a GFM table **anywhere between its
heading and the next heading** — prose may precede or follow the table
(savvy-web/systems#456, #457). A section with no table at all (prose or a
bullet list only) fails; the diagnostic is reported at the `## Dependencies`
heading in both lint engines.

The table itself must satisfy:

- **Columns** — exactly five, in order: `Dependency | Type | Action | From | To`.
- **Dependency** — non-empty package name.
- **Type** — one of `dependency`, `devDependency`, `peerDependency`,
  `optionalDependency`, `workspace`, `config`, `runtime`, `packageManager`.
  `runtime` is a language-runtime upgrade (e.g. the Node.js engine) and
  `packageManager` is the package manager's own self-upgrade (pnpm, bun, npm);
  both are release-neutral, like `devDependency`.
- **Action** — one of `added`, `updated`, `removed`.
- **From / To** — a semver string or the em-dash sentinel (`—`).
- **Semantic consistency** — `added` requires `From` = `—`;
  `removed` requires `To` = `—`.
- At least one data row.

## Why

The dependency table is machine-read: the changelog pipeline aggregates the
tables of all changesets in a release into one `### Dependencies` section, so
free-form prose or a list cannot substitute for the table. Prose alongside the
table is fine — only the table is parsed.

## Bad

```markdown
## Dependencies

- effect: 3.18.0 → 3.19.1
```

## Good

```markdown
## Dependencies

Routine dependency maintenance.

| Dependency | Type       | Action  | From   | To     |
| :--------- | :--------- | :------ | :----- | :----- |
| effect     | dependency | updated | 3.18.0 | 3.19.1 |
```

## Implementations

Both implementations share one section-scanning decision
(`src/changesets/utils/dependency-section.ts`) so they cannot drift:

- remark-lint: `src/changesets/remark/rules/dependency-table-format.ts`
- markdownlint: `src/changesets/markdownlint/rules/dependency-table-format.ts`

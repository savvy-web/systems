# CSH001 — changeset-heading-hierarchy

Validates heading structure in changeset files.

## What it checks

- **No h1 headings.** `#` is reserved for the version title the changelog
  formatter generates. Top-level sections in a changeset use h2 (`##`).
- **No depth skips.** Heading levels must increase sequentially — h2 may be
  followed by h3, but not by h4.

## Why

Changeset bodies are merged into a generated changelog whose version title is
an h1. An h1 in the body would collide with it, and skipped depths break the
rendered document outline.

## Bad

```markdown
# My Change

## Features

#### Deep sub-feature
```

## Good

```markdown
## Features

### Sub-feature

- Added dark mode support
```

# CSH004 — changeset-uncategorized-content

Detects content that appears before the first h2 heading in a changeset file.

## What it checks

Every content node before the first `##` heading is flagged. HTML comments
(and the YAML frontmatter block) are ignored — they are not "content".

## Why

Changelog rendering assigns content to a section by the h2 heading above it.
Content before the first heading belongs to no category and cannot be placed
in the generated changelog.

## Bad

```markdown
---
"@savvy-web/example": patch
---

Some orphan text explaining the change.

## Features

- Added search
```

## Good

```markdown
---
"@savvy-web/example": patch
---

## Features

Some text explaining the change.

- Added search
```

## Implementation

One `@effected/markdown-lint` rule, `src/changesets/lint/uncategorized-content.ts`, run by both hosts: `ChangesetLinter` (`savvy changeset lint`, the `changeset_validate` MCP tool) and markdownlint, through `@savvy-web/silk/changesets/markdownlint`. Both report the same findings on the same lines.

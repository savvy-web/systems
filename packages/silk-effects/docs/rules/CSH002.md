# CSH002 — changeset-required-sections

Validates that every h2 heading in a changeset matches one of the 13 known
section categories.

## What it checks

Every `##` heading must be one of (case-insensitive comparison):

Breaking Changes, Features, Bug Fixes, Performance, Documentation,
Refactoring, Tests, Build System, CI, Dependencies, Maintenance, Reverts,
Other.

## Why

Changelog rendering groups content by these categories in a fixed priority
order. An unrecognized heading cannot be mapped to a changelog section, so the
content would be lost or misplaced.

## Bad

```markdown
## Misc

- Changed a thing
```

## Good

```markdown
## Other

- Changed a thing
```
